"Kort om Aars" — key figures on the dark green band, orange numerals in a hairline grid.

**Intentional addition.** The Figma kit does not name a symbol `StatGrid`; this component is a confirmed intentional addition, built from the "Kort om Aars" key-figure band on the front page.

```jsx
<StatGrid items={["9\nselskaper","Nøkkeltall\nog info","123 m.nok\nfortjeneste","5000\nansatte","123 m.nok\ninvestert","Nøkkeltall\nog info"]} />
```

Six items in 3×2 is the canonical arrangement. Use \n to break value from label.
