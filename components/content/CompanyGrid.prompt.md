"Selskapene våre" — the portfolio logo wall.

**Intentional addition.** The Figma kit does not name a symbol `CompanyGrid`; this component is a confirmed intentional addition, built from the "Selskapene våre" logo wall in `Aars_Om-Aars.v.1` and `Aars_Forsiden.v.2`.

```jsx
<CompanyGrid companies={[{name:"Møller Mobility Group",logo:"/assets/companies/moller-mobility-group.png"}]} />
```

Logos sit on a beige band, capped at 201×94, optically centred. Never in boxes, never on white tiles.
