Pil — the only icon family in the identity. Eight outlined arrow glyphs taken from the kit's "Piler" set; use them for back-to-top, next/previous and off-site cues.

**Intentional addition.** The Figma kit does not name a symbol `Arrow`; this component is a confirmed intentional addition, built from "Piler" in `Komponenter` — the eight arrow glyphs.

```jsx
<Arrow direction="up" size={19} color="var(--white)" />
```

Directions: `up right down left up-left up-right down-left down-right`. Do not substitute an icon library — Aars has no other icons.
