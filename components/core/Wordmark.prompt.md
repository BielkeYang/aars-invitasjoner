Navnetrekket — the Aars wordmark, rendered from the supplied design file and masked so it can take any brand colour. Never redraw or re-typeset it.

Covers the `Aars_logo` Figma symbol (`hostfest.fig`, node `1:3`).

**Intentional addition.** The Figma kit does not name a symbol `Wordmark`; this component is a confirmed intentional addition, built from Navnetrekket — `Vector.svg` in `Komponenter`, plus the supplied `Aars_logo_svart.svg`.

```jsx
<Wordmark height={33} color="var(--aars-oransje)" />
```

Approved combinations: orange on light beige or dark green; light beige or white on orange or dark green; white or orange over imagery. When the mark stands alone, orange must be present — either in the mark or behind it.
