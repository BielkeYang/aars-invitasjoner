# UI kit — aars.no

Recreation of the Aars corporate site from `Aars_web.fig` (page *Design-Aars-7*).

| Screen | Source frames |
| --- | --- |
| `Forsiden.jsx` | `Aars_Forsiden.v.2_Desktop-1440`, `Aars_Forsiden_Tablet_750`, `Aars_Forsiden_Video_Mobil` |
| `OmAars.jsx` | `Aars_Om-Aars.v.1_Desktop-1440`, `Aars_Om_Aars_Mobil` |
| `Aktuelt.jsx` | `Aars_Aktuelt_Desktop-1440`, `Aars_Aktuelt-Tema_Desktop-1440` |
| `Artikkel.jsx` | `Aars_Erfaring-Eksempel-Artikkelmal_Desktop-1440` |
| `Kontakt.jsx` | `Aars_Kontakt_v2.1_Desktop-1440`, `Aars_Kontakt_v2.2/v2.3` |
| chrome in `index.html` | `Komponenter` (Meny/Footer), `Aars_Forsiden_Takeover_Meny_Overlay_Desktop-1440`, `Aars_Cookiebanner_Desktop` |

Interactive: the burger opens the takeover menu, menu items navigate, the
cookie banner accepts, the footer arrow scrolls to top. Designed at 1440.

Copy in the file is taken verbatim from the Figma frames; placeholder figures
("Nøkkeltall og info", "123 m.nok") are the designers' own placeholders and are
kept rather than invented over.
